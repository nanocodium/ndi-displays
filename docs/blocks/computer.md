# Computer

Desk chassis with tower, monitor, and keyboard. Placement records the owner. Right-click sits down at the machine. A lock is decided on the **server**, so a locked computer stays locked no matter what a client claims.

## Registry ID

`ndidisplays:computer`

See [Recipes](/reference/recipes) (`computer.json`).

## NDI behavior

The on-screen desktop can publish or preview NDI depending on the running app. See [Web Terminal](/blocks/web-terminal) when you need a full browser instead.
