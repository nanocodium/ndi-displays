# Equipment Rack

19-inch frame. Bolt units into slots: web module, PDU, switch, patch, recorder, sync, blank, and a rack router. Units rotate with the frame's facing.

## Registry ID

`ndidisplays:equipment_rack`

Unit items: `web_module`, `rack_pdu`, `rack_switch`, `rack_patch`, `rack_recorder`, `rack_sync`, `rack_blank`, `rack_router`.

## Crafting

See [Recipes](/reference/recipes) (`equipment_rack.json`). Units are separate items in the creative tab.

## NDI behavior

The rack router unit publishes a stable output name, same idea as the [NDI Router](/blocks/ndi-router) block. The web module needs [MCEF](/reference/integrations) on the broadcasting client.
