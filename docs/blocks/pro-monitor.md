# Pro Monitor

Production monitor chassis. The block-entity renderer puts a live NDI feed on the panel — direct video, no LED pitch or bezels.

## Registry ID

`ndidisplays:pro_monitor`

## Crafting

See [Recipes](/reference/recipes) (`pro_monitor.json`).

## Configuration

Right-click to pick the source. Use it on a desk next to the [Vision Switcher](/blocks/vision-switcher) or a [Multiview](/blocks/multiview).
