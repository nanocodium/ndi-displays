# Vision Switcher

ATEM-style desk. Right-click sits at the panel. The program output broadcasts as its own NDI source whether or not anyone is at the desk.

## Registry ID

`ndidisplays:vision_switcher`

## Crafting

See [Recipes](/reference/recipes) (`vision_switcher.json`).

## NDI behavior

**Send.** Preview / program buses pick discovered sources; the switched output is a stable name you can point a wall or [Pro Monitor](/blocks/pro-monitor) at.
